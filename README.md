# WatchParty

Watch videos with your friends in sync.

## How it works

1. Generate a room for you and your friends to connect to.
2. Send the password and room id to your friends.
3. Toggle on group leader.
4. Select a video to play.

## Features

- synced playback
- pause/play for all group members
- dynamic video source loads

## Getting Started

Read the README's in the frontend and backend folders to explain how to setup
that particular service.
